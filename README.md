# Olamide226 Tap

## How do I install these formulae?

`brew install olamide226/tap/<formula>`

Or `brew tap olamide226/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "olamide226/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
